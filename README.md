## Things I made when "just trying something" got out of hand

<table>
<tr>
<td width="50%" valign="top">

### Awaaj

For someone who can't speak out loud. Reports are hidden  
inside ordinary images using steganography, with AI help  
and a finder for the nearest NGOs, police and shelters.

**Next.js · FastAPI · MongoDB · Groq AI**

[view repository](https://github.com/Ishika1106/Awaaj)

</td>

<td width="50%" valign="top">

### Krishva

A farmer photographs a sick leaf. Krishva names the disease  
and speaks the remedy in Hindi or English.  
15 diseases, 20,000+ training images.

**React · FastAPI · TensorFlow · MobileNetV2**

[view repository](https://github.com/Ishika1106/Krishva)

</td>
</tr>

<tr>
<td width="50%" valign="top">

### Blessings Clinic

A calm, friendly website for a pediatric clinic in Delhi,  
so worried parents can find answers and book a visit  
without any stress.

**React · Firebase · SEO**

[visit live site](https://blessings-clinic.web.app/)

</td>

<td width="50%" valign="top">

### Cedar & Sage

A restaurant web experience built because  
apparently I cannot see a website without redesigning it.

**React · Vite · React Router · CSS**

[live site](https://cedar-sage.vercel.app) · [repository](https://github.com/Ishika1106/Cedar-Sage)

</td>
